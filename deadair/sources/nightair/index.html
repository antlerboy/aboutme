Instructions and tips

CDTIPS.DOC · Ben Taylor · 31 October 1995

NightAir Playlist Ben Taylor 31/10/95

Instructions and Tips

This is an easy to use system so it should only take a few minutes to come in, select tracks, and cue up the CDs.

So keep the box locked and tidy or everyone will be in trouble.

Put a tick next to each song you use on the main playlist. This helps to avoid the same track being used every day. Some tracks, especially AA and A, can happily be used several times.

Always check the track on the playlist corresponds with the one on the CD itself.

Don't give anyone the code who doesn't need it

Don't lose any CDs.

Rank is a vague guide only. AA is the best, then from A to D.

There are a few fade-outs, fade-ins, applause and live intros/outros. Tough.

Treat the CDs with respect. They belong to me, and my brother, who is bigger than me.

This is an eclectic mix which will add variety to the shows - but it should all be more or less suitable for night-time radio.

Time and thought has gone into making this easy to use, so please try to make it work. However, if there are any problems please get in touch with me and I will try to help. Ben [telephone number omitted]

The BASIC sorting program

LIST.BAS · Reads LIST3.TXT and writes five rank files

OPEN "list3.txt" FOR INPUT AS #1

OPEN "AA" FOR OUTPUT AS #2

OPEN "A" FOR OUTPUT AS #3

OPEN "b" FOR OUTPUT AS #4

OPEN "c" FOR OUTPUT AS #5

OPEN "d" FOR OUTPUT AS #6

DO UNTIL EOF(1)

INPUT #1, a$, b$, c$, d$, e$, f$

SELECT CASE a$

CASE "AA"

PRINT #2, a$; ","; b$; ","; c$; ","; d$; ","; e$; ","; f$

CASE "A"

PRINT #3, a$; ","; b$; ","; c$; ","; d$; ","; e$; ","; f$

CASE "B"

PRINT #4, a$; ","; b$; ","; c$; ","; d$; ","; e$; ","; f$

CASE "C"

PRINT #5, a$; ","; b$; ","; c$; ","; d$; ","; e$; ","; f$

CASE "D"

PRINT #6, a$; ","; b$; ","; c$; ","; d$; ","; e$; ","; f$

CASE ELSE

PRINT "ERROR"

PRINT a$; ","; b$; ","; c$; ","; d$; ","; e$; ","; f$

END

END SELECT

LOOP

CLOSE #1

CLOSE #2

CLOSE #3

CLOSE #4

CLOSE #5

CLOSE #6
